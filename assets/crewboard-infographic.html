Crewboard

프로젝트 보드를 기준으로 PM Agent가 역할별 서브에이전트를 조율하는 작업 운영 체계.

Board-led workflow 기획, 설계, 구현, 검증, 릴리스, 회고를 이슈와 산출물 기준으로 연결합니다.

Control System

보드 상태, PR, 권한 설정, 검증 기록으로 운영 규칙을 관리합니다.

Builder / Validator Split구현자와 검증자를 분리해 독립 검토를 유지합니다.
PM-only Transition보드 상태 전이와 이슈 close는 PM 전권입니다.
Evidence Before DoneREPORT, VERDICT, TR, PR 링크가 모두 남아야 합니다.
Human Merge GatePR approve 후 실제 머지는 사람이 수행합니다.

Rolling-wave Scope

큰 프로젝트는 전체 범위를 먼저 고정하고, 상세 AC는 활성 마일스톤마다 적시에 작성합니다.

MS1 AC
MS2+

FR 전수 추적성은 유지하고, 먼 마일스톤의 상세는 낡지 않게 미룹니다.

Evidence-based Delivery

각 이슈는 수용 기준, 구현 계획, 코드/테스트 근거, 리뷰 판정, 테스트 리포트, PR 머지 기록을 함께 남깁니다.
